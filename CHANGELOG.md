# Changelog

## [1.0.0] — 2026-03-04

### Initial Release

- Cinematic intro animation — multi-phase: outline, gradient fill, glitch, text reveal
- AI chatbot powered by Google Gemini 2.0 Flash with context-aware persona
- Dark / light theme with smooth CSS transitions
- Multilingual greeting cycle (Tamil, Hindi, French, Spanish, Chinese, Japanese, Arabic, Russian)
- Profile photo carousel — auto-cycles every 5 seconds, hover to advance
- Canvas-based background particle system
- Cursor-following radial glow effect (desktop)
- IntersectionObserver scroll reveal animations
- Responsive layout with mobile hamburger navigation
- Experience section with 3-role breakdown (Senior SWE, SWE, Intern)
- Project showcase: TaskForge, DiffLens, Portfolio — with live demo links
- Skills grid: Languages, Cloud & DevOps, Frameworks, Databases, Tools, Concepts
- Education section with relevant coursework
- Contact form via Formspree + direct links (LinkedIn, Email, Phone)
- Deployed on Vercel with CI/CD, custom domain, and environment variable security
